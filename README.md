# Flashcard Kanji N3 🌸

Flashcard interaktif Kanji JLPT N3 (nomor 1–370, kecuali 41–50) lengkap dengan gambar, romaji, dan contoh kata.

**Dibuat oleh Yogi**

## Fitur
- Kartu depan: kata contoh + gambar; belakang: cara baca (hiragana + romaji), arti, onyomi, kunyomi
- Filter per bagian atau per 10 kanji, mode acak, mode Kanji → Arti / Arti → Kanji
- Tandai "sudah hafal" (progres tersimpan di browser)
- Mendukung mode gelap, ramah HP

## Cara deploy ke GitHub Pages
1. Buat repository baru di GitHub (misalnya `kanji-n3-flashcard`).
2. Upload semua isi folder ini (`index.html`, `style.css`, `app.js`, `data.js`, folder `img`, dll.).
3. Buka **Settings → Pages**, pilih **Deploy from a branch**, branch `main`, folder `/ (root)`, lalu Save.
4. Tunggu 1–2 menit, situs ada di `https://USERNAME.github.io/kanji-n3-flashcard/`.

## Menambah kanji
Tambahkan baris di `data.js` dan simpan gambarnya sebagai `img/NOMOR.jpg`.

## Kredit
Materi dan ilustrasi berasal dari rangkuman Kanji N3 (Minna no Nihongo) milik pembuat aslinya. Hak cipta ilustrasi tetap pada pembuat asli.
